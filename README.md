## AIM

Create a gif from pictures inside a folder.


<br /><br />
## CONTENT
<br />

| File | Description |
| :--- | :--- |
| **gif_maker.py** | File to run. |
| **dataset** | Folder containing pictures as input. |
| **Licence.txt** | Licence of the release. |


<br /><br />
## INPUT
<br />

| Required files |
| :--- |
| ".jpg", ".jpeg", ".png", ".bmp", ".gif". |


<br /><br />
## HOW TO RUN

### 1. Prerequisite

Installation of:<br />
[Python](https://www.python.org/)<br />


### 2. Local running (personal computer)

- Download the *gif_maker.py* file ([here](https://github.com/gael-millot/gif_maker/archive/refs/heads/master.zip) for the last version. Otherwise, check the previous versions [here](https://github.com/gael-millot/gif_maker/tags)).
- Open it.
- Complete the *Parameters that need to be set by the user* section.
- Save the modifications.
- Linux execution: `python /mnt/c/Users/gmillot/Documents/Git_projects/gif_maker/gif_maker.py`
- Windows PowerShell execution: `python C:\Users\gmillot\Documents\Git_projects\gif_maker\gif_maker.py`

<br /><br />
## OUTPUT
<br />

An `output` folder where the `gif_maker.py` is located, containing:

| File | Description |
| :--- | :--- |
| **resized_\*** | The initial pictures resized according to the parameter settings. |
| **slideshow.gif** | The gif file. |
